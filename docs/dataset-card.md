# Original synthetic correction trajectories

Version: `original-world-v1`. Generator seed: 11 for the first pilot. All entities, sources, and text are synthetic. Fixture/generator text is original AI-assisted work, designated CC0-1.0; no external benchmark text or personal records are included. Source hashes cover exact UTF-8 text; offsets count Unicode code points.

The pilot contains 50 trajectories, each 6–10 observations. World transitions and expected states are specified before document rendering, without using the production proposer, validator or temporal view. Cases include reinforcement, real changes, authorized historical corrections, stale arrivals, future notices, retractions, conflicts, informal/injected instructions, and missing effective dates. Candidate values, dates, and authority are supplied annotations: this is not end-to-end text extraction.

Entities/aliases and template families are assigned to splits before rendering. `pilot` is development-only forever. Train/development/test/style-transfer generation uses disjoint entity identifiers and template families. No locked final test set has been created or inspected, and no paraphrase augmentation has occurred. The first trajectory guarantees action coverage; later event sequences vary under the fixed seed.

The educational Task 6 smoke froze a separate 20-trajectory training dataset (163 observations, identity `031f015fb0569ad1ba7e2bdc328d78b19f04a86c43fb576b7c1863d3cb0f8765`) and five-trajectory development dataset (44 observations, identity `3bbd47549bba3ce17bfc8fa741ba3fc906daa9de065d69529ab879bfd6346996`). Twenty training observations, four per action, supplied optimization targets. Two development requests supplied serialization probes only. Both bounded recipes use the exact same selected corpus; complete data/manifests are [committed with the default artifact](../examples/educational-sft/dataset/). The planned 600/100/150 full comparison splits and held-out style set remain uncreated.

Every dataset manifest records artifact hashes, generator version, seed, split, counts, license and review status. The loader verifies exact hashes, recomputed dataset identity, actual counts, unique IDs, group/gold joins, checkpoint ownership/time relationships and complete generated checkpoint coverage, plus predicate/value vocabulary. Keep `manifest.json`, observations, separate gold proposals, checkpoints and group records together. Dataset identity is independent of output-directory names.

Human reviewers: **0**. Labels are AI-authored and programmatically cross-checked, not independently human validated. `label-audit.jsonl` and `label-audit.md` in each run prepare up to 50 stratified pilot events with source, expected operation and checkpoints. Human reviewer/verdict fields start null. Record real disagreements/exclusions before scientific claims; the full training gate remains provisional until review. Synthetic coverage does not establish real-world generalization or novelty.
